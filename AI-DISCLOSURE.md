# AI use disclosure

**This project is built with heavy use of AI.** Large parts of the implementation — source code,
tests, fixtures, documentation and commit messages — are generated by large-language-model coding
agents working in a structured team workflow. A human maintainer sets the goals and milestone scope,
approves third-party dependencies, reviews the changes, and is responsible for what is committed.

This disclosure is intentionally visible: please read it before relying on the code, the
documentation or any claim in the repository.

## What this means in practice

- This is not a human-authored reference implementation. It is an AI-assisted learning project,
  and it is a toy browser, not a production browser.
- AI-generated code and prose can be confidently wrong, incomplete or out of date. Verify important
  claims against the source, the tests and the current documentation instead of trusting a summary.
- Verification is taken seriously: the project keeps deterministic CTest suites, warning-free GCC
  and Clang builds, continuous integration, byte-compatibility gates and human review. That reduces
  mistakes but cannot cover everything; independent review is welcome.
- Contributions are reviewed with the same context. See [CONTRIBUTING.md](CONTRIBUTING.md).
- The code is provided under the [MIT license](LICENSE) without warranty.

## How the work is organised

The repository documents the process openly: milestones and acceptance criteria live in
[docs/roadmap.md](docs/roadmap.md), the design is recorded in
[docs/architecture.md](docs/architecture.md), locked decisions in
[docs/decisions.md](docs/decisions.md), and the round-based development workflow in
[docs/team-workflow.md](docs/team-workflow.md). The rules given to the AI agents are in
[AGENTS.md](AGENTS.md).

If you believe a change or a claim is wrong, please open an issue or a pull request with a
reproduction — that is the most useful review this kind of project can receive.
