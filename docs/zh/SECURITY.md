# 安全策略

## 范围与预期

toybrowser 是一个实验性学习项目，不是加固过的浏览器。它只实现一小部分 HTML/CSS 与渲染，没有
JavaScript 引擎，也没有沙箱；不要用它浏览不可信页面，也不要输入敏感信息。任何抓取到的页面、图片
或字体都应当按不可信输入处理。

唯一刻意实现的安全特性是 HTTPS：证书链与主机名校验始终开启，没有 insecure 模式，也没有关闭校验的
方法。HTTP 响应受 body 大小上限与超时限制。

## 支持的版本

只有 `main` 分支受支持。没有发布分支或 backport。

## 报告漏洞

请**不要**为疑似漏洞开公开 issue。使用仓库的私有安全报告渠道（例如 GitHub 的
“Report a vulnerability” / 私有安全公告），并附上：

- 受影响的命令或页面；
- 最小复现；
- 观察到的影响与预期行为；
- 测试的提交或版本。

我们会尽力确认。这是业余项目，不提供响应时间或修复时间保证。

## 已知的非问题

- `tests/fixtures/tls/` 中的私钥与证书只为进程内 loopback TLS 测试生成，不链接到任何公开信任链，
  并已在文档中明确为仅测试用。它们出现在仓库中是刻意的，不是泄漏的密钥。
- 已安装字体、窗口管理器或发行版不同导致的渲染差异不是安全问题。
- 页面在渲染时消耗 CPU 或内存对于未加固的玩具浏览器是预期行为；只有绕过文档化限制或看起来像
  内存不安全的崩溃才需要报告。
