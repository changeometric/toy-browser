# 依赖

策略本身在 [AGENTS.md](../../AGENTS.md)。本文件记录实际允许什么、还在申请什么。

## 当前清单

**目前链接了一个第三方库：libX11（MIT/X11）**，用于 X11 窗口后端。其他一切都是 C++20 标准库和标准 POSIX 接口。libpng、zlib 和 freetype 已获批供以后使用（M8），但尚未链接。没有使用 HTML 解析器、CSS 引擎、JS 引擎、布局引擎或浏览器引擎——那些都在本仓库中编写。

## 当前已批准

用户于 2026-10-31（M1 开始时）批准：

- **libX11**——Linux 上的窗口、输入与像素呈现，自 M1 起使用。许可证：MIT/X11。通过 CMake 的 `find_package(X11)` 链接；不做 vendoring。引入于提交 `0572b8b`（M1）。
- **libpng + zlib**——允许用于图像解码，计划 M8。尚未链接。
- **freetype**——允许用于字体光栅化与度量，计划 M8。尚未链接。
- **libxcb**——允许作为替代窗口库；当前未使用。

其他什么都没链接。C++20 标准库和标准 OS/POSIX 接口仍是默认。所有已批准的候选库都使用与项目 MIT 许可证兼容的宽松许可证。

## 系统接口仍然是依赖

任何与显示服务器通信的东西（例如 X11 客户端库）在本项目中都算第三方依赖，需要审批。libX11 现在已获批用于窗口；headless 后端——渲染到内存并写 PPM 文件——让整条流水线在无显示器时可测试。

## 依赖候选

| 候选 | 用途 | 自写替代方案 | 粗略成本 | 状态 |
| --- | --- | --- | --- | --- |
| libX11 | 窗口、输入、呈现像素 | 自己实现 X11 线协议 | 中等；协议怪癖、XShm 回退 | **已批准，自 M1 起在用**（先用普通 `XPutImage`；需要时再上 XShm） |
| libxcb | 同上，API 更现代 | 同上 | 中等 | **已批准，未使用**（libX11 的替代） |
| freetype | TTF 字形光栅化与度量 | 自写子集 TTF 加载器（cmap/glyf/hmtx，无 hinting） | 中等 | **M8 已批准，尚未链接**——先位图字体 |
| libpng + zlib | PNG 解码 | 自写 inflate + PNG filters/decoder | 约 600–900 行，很有教育意义 | **M8 已批准，尚未链接** |
| OpenSSL | TLS，即 `https://` | 从零实现不现实 | 高 | **已推迟，未批准**——在决定前只支持 HTTP/file |
| stb_truetype / stb_image | 单头文件即插即用实现 | 自写实现 | 低 | **未批准**——与本项目的精神冲突 |
| harfbuzz / fontconfig / icu | 复杂整形、字体发现、Unicode 数据 | 先做基础整形与 ASCII/拉丁 | 高 | **不计划** |

今天只链接 libX11。任何其他行都需要先完成下面的流程。

## 审批流程

1. Agent 说明：用途、许可证、规模与维护负担，以及自写替代方案。
2. 用户回答是或否。
3. 若是：在本文件记录库、包/版本、日期以及引入它的提交；通过 CMake（`find_package` 或 `pkg-config`）链接，除非用户要求，否则不做 vendoring。
4. 如果机器上缺少该包，请用户安装——agent 自己从不安装任何东西。
5. 若否：实现自写替代方案，或推迟该功能。

## 保持代码树可移植的规则

- 代码或 CMake 中不使用绝对路径，不硬编码库版本或包位置。
- 库只能通过 CMake find 模块或 pkg-config 发现，且必须在审批之后。
- 可选功能必须能优雅降级：没有可选依赖时测试也能通过。headless 运行不需要显示器，但当前二进制仍然链接 libX11，因为窗口后端总是会被构建。
- 不要假设某台机器上有什么字体、窗口管理器、GPU 或包。
